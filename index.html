How to Add a New Mini Project

  1. Duplicate the template:

    Copy the pre-configured folder projects/template/ to projects/XX-your-project/ (e.g. projects/02-counter/).

  2. Implement your code:

    Write your semantic HTML in index.html, styling in styles.css, and logic in app.js.

  3. Register in projects.json:

    Add a new JSON object entry with id, title, description, tags, and path.

  4. Instant Hub Integration:

    Your new project will immediately appear on this dashboard with search, filtering, and live iframe previews!
