# 💬 #04 - Aura Testimonials: Interactive Review Carousel

> Responsive customer testimonial carousel featuring auto-play with circular SVG countdown timer, touch swipe support, verified reviewer badges, and review submission modal.

---

## 🌟 Key Features
- **Auto-Play with SVG Timer Ring:** Smooth continuous rotation with an animated circular progress indicator (automatically pauses on hover).
- **Interactive Controls:** Previous, Next, and "Surprise Me / Random" buttons.
- **Touch & Mobile Friendly:** Seamless swipe gesture detection (`touchstart` / `touchend`).
- **Review Submission Modal:** Visitors can submit their own review with name, company, rating, and feedback, immediately stored to `localStorage`.
- **Keyboard Navigation:** Left/Right arrow keys and Spacebar for random review.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
