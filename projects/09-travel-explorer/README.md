# 🗺️ #09 - Wanderlust Explorer: Curated Travel Experiences

> An interactive travel portal featuring categorized expedition filtering, seasonal adventure highlights, tour reservation booking modal, and responsive mobile navigation.

---

## 🌟 Key Features
- **Destination Filtering:** Filter packages by category (All, Rainforest, Alpine, Coastal) with price indicators and customer review ratings.
- **Interactive Booking Modal:** Reservation form with dynamic destination selection, date picker validation, and guest counter.
- **Seasonal Showcase:** Dedicated visual showcases for Spring, Summer, and Winter expeditions.
- **Responsive Mobile Navigation:** Hamburger slide-out drawer with backdrop blur and smooth anchor scroll navigation.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
