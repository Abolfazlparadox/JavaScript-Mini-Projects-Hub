# ⏱️ #05 - PulseGauge: Circular Progress & Gauge Studio

> An interactive circular progress and gauge studio built with SVG stroke-dash calculations, featuring manual gauge controls, a Pomodoro focus timer, an upload simulator, and dynamic gradient palettes.

---

## 🌟 Key Features
- **SVG Stroke Math:** High-precision SVG `stroke-dashoffset` and `stroke-dasharray` mathematics calculating dynamic angles on-the-fly.
- **Multi-Mode Studio:**
  1. *Manual Gauge:* Real-time slider and preset percentage buttons (25%, 50%, 75%, 100%).
  2. *Pomodoro Focus Timer:* Configurable 25min focus, 5min short break, and 15min long break countdown with remaining mm:ss.
  3. *Upload Simulator:* Simulates realistic data streaming with transfer rates and completion alerts.
- **Dynamic Gradient Theming:** 4 color palettes (Ocean Breeze, Sunset Fire, Emerald Luxe, Cyber Neon) modifying SVG gradient stops.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
