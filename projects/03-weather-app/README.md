# 🌤️ #03 - SkyPulse Weather: Dynamic Meteorological Studio

> Modern meteorological forecast dashboard featuring live OpenWeatherMap API integration, an offline smart-fallback engine, 5-day forecasts, geolocation, and dynamic unit toggles.

---

## 🌟 Key Features
- **Dual Meteorological Engine:** Connects to live weather APIs and gracefully falls back to a smart simulated forecast engine when offline or if rate limits occur.
- **5-Day Extended Forecast:** Visual forecast cards showing anticipated conditions and temperatures.
- **Atmospheric Metrics:** Live humidity, wind velocity with units, feels-like temperature, and barometric pressure.
- **Unit Conversion:** Real-time conversion between Metric (°C, km/h) and Imperial (°F, mph).
- **Geolocation API:** One-click instant weather lookup for the user's current coordinates.
- **Quick City Chips:** Fast one-click access to global capitals (Tehran, London, New York, Tokyo, Paris).

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
