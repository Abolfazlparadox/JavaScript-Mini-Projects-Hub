# 🌐 #08 - SocialSphere: Interactive Social Feed Studio

> A modern responsive social media feed application featuring dynamic post creation with photo attachments and emojis, animated like reactions, live comment drawer, and a story viewer modal.

---

## 🌟 Key Features
- **Dynamic Post Publishing:** Create and publish rich posts directly into the live feed with photo attachments and emoji insertion.
- **Interactive Reactions:** Live like button toggling reaction counters and active states.
- **Live Comments Drawer:** Add comments that immediately render into the post's comment stream with real-time counter updates.
- **Ephemeral Story Viewer:** Clicking any contact story opens a dedicated story modal with an animated progress countdown timer.
- **Share to Clipboard:** Instant post URL copy with toast notification.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
