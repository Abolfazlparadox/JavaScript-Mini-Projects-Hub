# 🎴 #26 — MemoDeck Flashcards

> Spaced-repetition flashcard system with 3D flip study mode, SM-2-lite scheduling, decks and retention stats.

---

## 🌟 Features

- **Deck + card CRUD** — questions/answers, deck detail browser, move cards between decks
- **Study mode** — 3D card flip, Again/Hard/Good/Easy grading, progress bar
- **SM-2-lite engine** — ease factor, growing intervals, 10-min relearn, re-queue on Again
- **Analytics** — due counts, per-card review stats, global retention %
- **Shortcuts** — `S` study, `D` deck, `N` card, `Space` flip, `1–4` grade

## 🛠️ Tech Stack & Web APIs

- **Engine:** spaced-repetition scheduling math • **UI:** CSS 3D transforms • **Storage:** LocalStorage

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
