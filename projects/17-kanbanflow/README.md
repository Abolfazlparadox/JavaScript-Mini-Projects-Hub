# 📋 #17 — KanbanFlow Board

> Interactive agile kanban board with native HTML5 drag & drop, dynamic swimlanes, priorities, tags, due dates, search/filter and JSON backup.

---

## 🌟 Features

- **Native Drag & Drop API** — smooth cross-column moves with live drop position + hover ring
- **Dynamic swimlanes** — add / rename / recolor / reorder / clear / delete columns
- **Rich cards** — title, description, priority badges, `#tags`, due dates with overdue flags
- **Touch & mobile friendly** — ◀ ▶ move buttons, horizontal scroll board
- **Search + priority filter**, done-ratio progress bar
- **Backup suite** — JSON export / validated import, LocalStorage autosave, sample seed + reset
- **Shortcuts** — `N` new card, `C` new column, `/` search, `Esc` close

## 🛠️ Tech Stack & Web APIs

- **DnD:** HTML5 Drag and Drop API with insertion-index math
- **Web APIs:** LocalStorage, FileReader, Blob download, native dialogs

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
