# 💰 #20 — SpendWise Tracker

> Smart expense tracker with monthly budgets, category analytics on canvas, 6-month trends, filters and CSV export.

---

## 🌟 Features

- **Expense CRUD** — title, amount, 8 categories, date + month navigation
- **Budget ring** — SVG gauge with green → amber → red states + remaining math
- **Canvas analytics** — category donut with legend, 6-month bar trend
- **Search + category filter**, CSV export, seeded demo history
- **Shortcuts** — `N` new expense, `B` budget, `/` search

## 🛠️ Tech Stack & Web APIs

- **Rendering:** Canvas 2D donut + bars, SVG ring math • **Storage:** LocalStorage • **Export:** Blob CSV

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
