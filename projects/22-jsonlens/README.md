# 🧬 #22 — JSONLens Studio

> Format, validate, minify and explore JSON with live error pinpointing, syntax highlighting and a collapsible tree view.

---

## 🌟 Features

- **Live validation** — validity pill, error message + exact line highlight in gutter
- **Pretty / Minify** — 2-space, 4-space or tab indent, one click
- **Syntax colors** — keys, strings, numbers, booleans, null
- **Tree explorer** — recursive collapsible `<details>` view of any document
- **Doc stats** — key count, max depth, byte size
- **File I/O** — load `.json`, download, copy, sample doc, autosave

## 🛠️ Tech Stack & Web APIs

- **Parsing:** native JSON engine + position recovery • **Storage:** LocalStorage • **I/O:** FileReader, Blob, Clipboard

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
