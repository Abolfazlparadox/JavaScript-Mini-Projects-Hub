# 🎡 #27 — ChoiceWheel Spinner

> Physics-based decision wheel with weighted slices, tick sounds, confetti winner celebration and spin history.

---

## 🌟 Features

- **Weighted wheel** — slice sizes from ×1–×5 weights, 12-color palette, auto labels
- **Spin physics** — 5–9 turns with easeOutQuart, per-segment tick sounds
- **Winner modal** — confetti particle engine, fanfare, remove-winner re-spin
- **History** — last 20 winners with timestamps, persisted
- **Shortcuts** — `Space` spin, `Enter` re-spin, `Esc` close

## 🛠️ Tech Stack & Web APIs

- **Rendering:** Canvas 2D wheel + confetti particles • **Audio:** Web Audio ticks/fanfare • **Storage:** LocalStorage

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
