# 🖼️ #06 - Lumina Gallery Pro: Responsive Lightbox & Showcase

> Modern responsive photo gallery featuring category filter tabs, interactive fullscreen lightbox modal, keyboard navigation, image download, and thumbnail filmstrip.

---

## 🌟 Key Features
- **Responsive Fluid Grid:** Responsive card layout with smooth hover elevation and gradient overlay info.
- **Interactive Lightbox Modal:** Fullscreen modal with high-res photo viewer, previous/next controls, and image counter (`1 of 6`).
- **Keyboard Navigation:** Support for <kbd>←</kbd> and <kbd>→</kbd> arrow keys to slide, and <kbd>Esc</kbd> to close.
- **Category Filter Tabs:** Fast client-side filtering across categories (All, Nature, Urban, Minimal).
- **Thumbnail Filmstrip:** Bottom thumbnail preview bar inside the lightbox for instant jumping between images.
- **Image Download:** One-click image download with automatic filename generation.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
