# 🔐 #07 - AuthCraft Portal: Modern Authentication Suite

> Modern authentication portal featuring 3-way sliding tab forms (Sign In, Sign Up, Recovery), real-time form validation, password strength analysis, visibility eye toggle, and persistent session simulation.

---

## 🌟 Key Features
- **3-Way Sliding Transitions:** Seamless switching between Sign In, Sign Up, and Password Recovery.
- **Real-Time Password Strength Meter:** Dynamic 4-tier entropy calculation analyzing character length, numbers, symbols, and uppercase variations.
- **Show / Hide Password:** Accessible eye toggle on password inputs.
- **Mock Session & LocalStorage Engine:** Saves registered user accounts in browser memory, verifies login credentials, and shows a verified user dashboard with logout.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
