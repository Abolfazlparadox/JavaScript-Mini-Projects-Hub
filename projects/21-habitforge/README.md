# 🔥 #21 — HabitForge Tracker

> Build unbreakable streaks with weekly check-ins, GitHub-style heatmap, XP levels and per-habit targets.

---

## 🌟 Features

- **Habit CRUD** — name, 12 icons, 8 colors, weekly targets (1–7)
- **Trailing-7-day grid** — tap to check in, today ring, animated dots
- **Streak engine** — consecutive-day math with today-pending tolerance
- **Heatmap** — 18 weeks × 7 days, all habits combined, intensity levels
- **Gamification** — XP points + sqrt-based levels, best-streak + today-% stats
- **Shortcut** — `N` new habit, `Esc` close

## 🛠️ Tech Stack & Web APIs

- **State:** streak/date math, LocalStorage persistence • **UI:** CSS grid heatmap, no deps

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
