# 🗃️ #25 — SnippetVault

> Personal code-snippet manager — save, tag, search and one-click-copy reusable code across 9 languages.

---

## 🌟 Features

- **Snippet CRUD** — title, language, description, tags, favorites
- **Power search** — across title, code, tags + language filter + favorites-only
- **One-click copy** — Clipboard API with fallback, per-card actions
- **Backup** — JSON export / validated import
- **Shortcuts** — `N` new, `/` search, `Esc` close

## 🛠️ Tech Stack & Web APIs

- **Storage:** LocalStorage vault • **I/O:** Clipboard, FileReader, Blob download

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
