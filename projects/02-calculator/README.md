# 🔢 #02 - CalcPro Studio: Modern Engineering Calculator

> A sleek, accessible glassmorphic calculator with safe evaluation, history tape, scientific operations, and keyboard navigation.

---

## 🌟 Features
- **Safe Calculation Engine:** Built without dangerous `eval()`, using safe token evaluation and floating-point error correction.
- **Scientific Functions:** Square root (`√`), square (`x²`), percentage (`%`), and sign toggling (`±`).
- **Calculation History Tape:** Interactive history panel preserving past equations. Click any past result to recall it to the display.
- **Memory Functions:** Standard `MC`, `MR`, `M+`, and `M-` registers.
- **Keyboard Navigation:** Full support for Numpad, arithmetic operators, Enter, Backspace, and Escape.
- **Tactile Sound Effects:** Synthesized audio click feedback via the Web Audio API.

## 🚀 How to Run
Open `index.html` in your browser or launch it directly from the root Showcase Hub.
