# 🧾 #28 — InvoiceForge Generator

> Build polished, print-ready invoices with line items, tax/discount math, status stamps and JSON backup.

---

## 🌟 Features

- **Full editor** — business + client blocks, invoice no/dates/currency/status
- **Line items** — inline desc/qty/rate editing, instant totals
- **Smart totals** — subtotal, tax %, discount %, shipping, grand total
- **Live paper preview** — light print-ready design with status stamp
- **Print / PDF** — dedicated print CSS (editor hidden, paper only)
- **Backup** — JSON export/import, autosave, `A` add item, `P` print

## 🛠️ Tech Stack & Web APIs

- **Rendering:** live DOM preview + print media CSS • **Storage:** LocalStorage autosave • **I/O:** FileReader, Blob

## 🚀 How to Run

1. Open `index.html` directly in any browser, or launch it from the root Hub.
