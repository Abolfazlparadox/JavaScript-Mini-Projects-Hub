## 📖 Overview

**Paradox CodeLab** is a curated monorepo engineered by **Abolfazl Mohammadshahi (Paradox)**. It demonstrates core DOM manipulation, asynchronous browser APIs, state machines, canvas physics, and accessible UI engineering—crafted with **zero runtime dependencies and 100% native web APIs**.

The repository features an interactive **Central Showcase Hub** (`index.html`) equipped with:
- 🔍 **Real-Time Live Search:** Sub-millisecond keyword lookup across titles, tags, and architectural concepts (`Ctrl + K`).
- 🏷️ **Dynamic Category Filters:** Quickly isolate Portfolios, DOM visuals, UI components, state engines, media, and utilities.
- 📱 **Embedded Iframe Device Previews:** Test each application directly within the hub in Desktop (100%), Tablet (768px), or Mobile (375px) viewports.
- 🌓 **Persistent Theme Switcher:** Dark & Light glassmorphic design system stored via `localStorage`.
- 🕶️ **Integrated Personal Portfolios:** Single-click access to 3 distinct portfolio experiences (Noir Dark, Minimalist Dev, and Stellar Executive).

## ⚡ Quick Start

Because this repository uses native web standards, **no build step, bundler, or package installation is required**.

### Option A: Direct Browser Preview
Double-click `index.html` at the repository root to open the Showcase Hub directly in your browser.

### Option B: Local Static Server (Recommended)
```bash
# Clone the repository
git clone https://github.com/AbolfazlParadox/JavaScript-Mini-Projects-Hub.git
cd "JavaScript-Mini-Projects-Hub"

# Start local server (using npx without permanent install)
npx serve .
```

Then open `http://localhost:3000` in your browser.

## 🛠️ How to Add a New Project

1. **Duplicate the Template:**
   ```bash
   cp -r projects/template projects/13-your-project
   ```
2. **Build Your Feature:**
   - Write semantic HTML in `projects/13-your-project/index.html`
   - Style in `projects/13-your-project/styles.css`
   - Implement logic in `projects/13-your-project/app.js`
3. **Register in `projects.json`:**
   Add a new JSON object entry with `id`, `title`, `description`, `tags`, and `path`.
4. **Instant Hub Integration:**
   The project will instantly appear in the Central Hub with live search, category tagging, and iframe previews!
