## 📖 Overview
Color Flipper is a lightweight, interactive frontend mini-project built with pure vanilla JavaScript, HTML, and CSS. The core functionality revolves around a central button that, when clicked, dynamically generates and applies a new background color to the webpage. This project serves as a practical demonstration of core DOM manipulation and event handling.

## ✨ Features
* **Dynamic Color Generation:** Instantly changes the background color upon user interaction.
* **Vanilla JavaScript:** Built without any external libraries or frameworks to focus on core logic.
* **Minimalist UI:** Clean, centered, and responsive design focusing entirely on the core functionality.

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3
* **Logic:** JavaScript (ES6+)

## 🚀 How to Run (Quick Start)
Since this is a static frontend project, no complex setup or server configuration is required.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Abolfazlparadox/color-flipper.git](https://github.com/Abolfazlparadox/color-flipper.git)
   cd color-flipper

    ```

2. **Open the project:**
Simply double-click the `index.html` file to open it in your default web browser.

*(Alternatively, you can host it for free using GitHub Pages so anyone can view it online with a single click.)*
